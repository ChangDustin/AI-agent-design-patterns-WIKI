## 1. LLM 的提案

### 這篇在講什麼

1. **核心想法**：以前「推理」（思維鏈）和「行動」（產生動作計畫）是分開研究的。ReAct 讓 LLM **交錯產生「想法」和「動作」**：想法幫助擬定、追蹤、更新計畫，也能處理例外（為了行動而推理）；動作則從外部（例如 Wikipedia）取得新資訊來支持推理（為了推理而行動）。
2. **論文自己的比喻：煮菜。** 兩個動作之間，人會在心裡想：「菜都切好了，該燒水了」（追蹤進度）、「沒有鹽，那改用醬油和胡椒」（處理例外）、「麵糰怎麼做？上網查一下」（發現需要外部資訊）；也會為了想清楚而去行動（翻食譜、打開冰箱看有什麼）。
3. **運作方式**：每一輪是「想法（Thought）→ 動作（Action）→ 觀察（Observation）」。想法不會改變外部環境，只會更新上下文。想法的用途包括拆解目標、注入常識、從觀察中抽出重點、追蹤進度、處理例外。問答類任務每一步都想（密集）；需要很多動作的任務只在關鍵處想（稀疏，由模型自己決定）。
4. **工具很陽春**：問答任務只給三個動作：`search[實體]`（回傳 Wikipedia 頁面前 5 句）、`lookup[字串]`（像 Ctrl+F 找下一句）、`finish[答案]`。這是故意設計得很弱，模擬人怎麼查 Wikipedia。
5. **結果（只用 1～6 個示範例子，不用訓練）**：
   - **ReAct 永遠贏過「只做不想」（Act）**：推理能引導行動。
   - **和思維鏈（CoT）互有勝負**：事實查核 FEVER 上 ReAct 贏（60.9 vs. 56.3），多步問答 HotpotQA 上略輸（27.4 vs. 29.4）。
   - **錯誤分析很有教學價值**（HotpotQA 抽 200 條軌跡人工標註）：CoT 失敗的案例裡 **56% 是幻覺**，ReAct 是 **0%**；但 ReAct 的推理錯誤較多（47% vs. 16%），常見的是**卡在迴圈裡重複同樣的想法和動作**；另外 23% 的失敗來自搜尋沒找到有用資訊，一旦搜歪就很難拉回來。
   - **兩者合用最好**：ReAct 跑太多步還沒答案（HotpotQA 7 步）就改用 CoT 自洽投票；投票不夠一致時改用 ReAct。內部知識＋外部資訊一起用。
   - **互動任務大勝**：文字家務遊戲 ALFWorld 成功率 71%（只做不想 45%、用十萬筆示範訓練的模仿學習 37%）；購物網站 WebShop 成功率 40%（只做不想 30%），但仍遠低於人類專家（約 60%）。
   - **微調後更強**：用 3,000 條軌跡微調，小模型（8B）的 ReAct 就勝過大 7 倍模型的所有提示法。
6. **可解釋、可介入**：人看得到推理過程，分得出哪些來自模型內部知識、哪些來自外部；人只要**改掉一兩句想法**（刪掉幻覺的句子、補一點提示），代理的行為就會大幅改變並完成任務。
7. **限制與倫理**：動作空間大的複雜任務需要更多示範，很快就超過上下文長度；提示法仍遠不如專門訓練的方法。讓 LLM 能對外行動有風險（查到不當或私人資訊、做出有害動作），所以實驗只限在 Wikipedia 和不會真的下單的 WebShop。

### 想問作者的問題

1. **ReAct 的比喻**：直接用論文自己的**煮菜**比喻（切好菜 → 想「該燒水了」；沒鹽 → 想「改用醬油」；不會做麵糰 → 想「上網查」）。這是論文原生的比喻，最有說服力。
2. **要不要加一個自編的中文示範例？** 論文的例子（Apple Remote、在虛擬房間裡找胡椒罐）對台灣學生有點遠。我建議在 ReAct 頁加一個標明「自編」的例子，示範一輪完整的迴圈，例如「出門要不要帶傘？」：想「要先知道會不會下雨」→ 動作「查天氣[台北]」→ 觀察「降雨機率 80%」→ 想「機率很高」→ 動作「完成[帶傘]」。觀察結果是假設的，不涉及真實數據，會標「Wiki 綜合（自編教學例）」。
3. **ReAct 歸在哪一類？** 建議 Wiki 定位成「**工具使用＋思維鏈的結合，也是代理最小的原型**」，並註明 Weng 把它放在反思一節。這樣簡報可以把 ReAct 當成從「模式」走到「代理」的那座橋。
4. **數字怎麼取捨？** 論文數字很多，我建議簡報最多用兩組，Wiki 則完整記錄：
   - **(a)** HotpotQA 錯誤分析：CoT 失敗案例中 56% 是幻覺，ReAct 是 0%（但 ReAct 推理錯誤較多）。可以說明「接上外部資訊能減少瞎掰，但也會卡關」。
   - **(b)** ALFWorld 成功率：71% vs. 45%，差別只在有沒有「想」的步驟。

## 3. 決定

作者同意整份提案，四個問題都採用 LLM 的建議：

1. **比喻**：用論文原生的「煮菜」比喻。
2. **自編中文例**：ReAct 頁加入「出門要不要帶傘？」，標「Wiki 綜合（自編教學例）」，觀察結果是假設的。
3. **定位**：ReAct＝工具使用＋思維鏈的結合，也是代理最小的原型；頁面註明 Weng 把它放在自我反思一節。
4. **數字**：簡報最多用兩組（幻覺 56% vs. 0%、ALFWorld 71% vs. 45%）；Wiki 完整記錄。
